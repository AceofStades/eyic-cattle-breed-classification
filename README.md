# Cattle Breed Classification

[DATASET LINK](https://www.kaggle.com/datasets/lukex9442/indian-bovine-breeds)

- augment.py -> Augments images to balance the imbalance classes in the dataset. (Adds upto 500 images per class)
- model.py -> Trains on pre-trained MobileNetV3-large model.
- evaluate.py -> Evaluates on the test set.

- old-model/ -> Old depracated scripts
- model_small.py -> Depracated, Trains on MobileNetV3-small model.
